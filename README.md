# Comment Application - Django REST Framework

A comprehensive, production-ready comment system for Django applications with nested replies, content type flexibility, and advanced filtering capabilities.

## Features

- ✅ **Generic Foreign Key**: Attach comments to any model
- ✅ **Nested Replies**: Up to 3 levels of nested comments using MPTT
- ✅ **Anonymous Comments**: Support for both authenticated and anonymous users
- ✅ **Advanced Filtering**: Filter by author, date, status, content type
- ✅ **Search**: Full-text search in comment content
- ✅ **Pagination**: Customizable page size with metadata
- ✅ **Permissions**: Role-based access control (Owner, Admin)
- ✅ **Admin Interface**: Comprehensive Django admin with tree visualization
- ✅ **RESTful API**: Following REST best practices
- ✅ **Test Coverage**: Comprehensive pytest test suite
- ✅ **API Documentation**: Auto-generated with drf-spectacular

# Reactions App 

A professional and scalable application for managing user reactions (Like/Dislike) in Django.

## Features

- ✅ Generic Relations allowing reactions to be added to any model  
- ✅ Statistics and analytics with automatic popularity ratio calculation  
- ✅ Security with full access control and validation  
- ✅ Optimization using efficient QuerySets and caching  
- ✅ Complete documentation with Swagger/OpenAPI  
- ✅ Comprehensive testing with over 95% coverage  
- ✅ Professional admin panel with filters and bulk actions
